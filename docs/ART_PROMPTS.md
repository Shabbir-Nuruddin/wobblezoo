# Wobble Zoo — Animal Art Prompt Pack (v1)

Goal: 8 original, **stylized-realistic** (Pixar/3D-render) fluffy animals for the merge
chain. Legally safe to ship because each is a brand-new AI creation (not derived from any
specific photo). Use a tool that grants **commercial rights** (e.g. Spritesheets.AI,
getimg.ai paid, SEELE Pro). Keep a screenshot of the tool's commercial-license terms.

## Shared style anchor (keep this identical for ALL 8 so they feel like one family)
> 3D stylized-realistic render, Pixar / DreamWorks animation style, adorable fluffy
> {ANIMAL}, big soft expressive glossy eyes, ultra-soft detailed fur, chubby wholesome
> proportions, sitting upright and front-facing, centered with a small margin, gentle warm
> studio lighting, soft shadow under the body, endearing happy expression, clean solid
> pure-white background, high detail, 1:1 square, mobile game character.

## Negative prompt (paste into the "negative" field every time)
> text, watermark, logo, signature, multiple animals, cluttered or busy background,
> dark, scary, gore, human, hands, deformed, extra limbs, blurry, low quality, harsh shadows

## Technical settings
- Aspect ratio: **1:1 square**, resolution **1024×1024** (or higher).
- Background: **pure white** (or one flat pastel) so I can cut it to transparent cleanly.
- Generate **3–4 variations** per animal, keep the cutest that matches the family.
- Front-facing, full body, sitting. Whole animal inside the frame with a little margin.
